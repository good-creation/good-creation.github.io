# good-creation.github.io

good-creation Organization の GitHub Pages ルートリポジトリ。
現在このリポジトリ自体はプレースホルダーで、公開しているコンテンツはありません。

Organization 配下のサイトはそれぞれ独立したリポジトリで管理しています。

| サイト | リポジトリ | URL |
|---|---|---|
| 合同会社O.C.K コーポレートサイト | [good-creation/ock-oita](https://github.com/good-creation/ock-oita) | https://ock-oita.com |
| Anthropic 公式コース 学習ノート | [good-creation/claudestudying](https://github.com/good-creation/claudestudying) | https://good-creation.github.io/claudestudying/ |

> このリポジトリは Organization Pages のため、ここに独自ドメインを設定すると
> `good-creation.github.io` 配下の**全プロジェクトがそのドメイン配下に入る**。
> 個別サイトの独自ドメインは、必ず各プロジェクトのリポジトリ側で設定すること。
