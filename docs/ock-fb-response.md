## 2. 変更点（実装内容）

### 2-1. 写真に工程キャプションを追加 — FB2・FB3

**対象**: `index.html`（8枚）、`service.html`（5枚）

写真流し（marquee）の各カットを `<li><img>` から `<li><figure><img><figcaption>` に変更し、
**画面上に工程名が出る**ようにした。これまでは `alt` 属性にしか説明がなく、読み上げ以外では見えなかった。

並び順も実際の工程順に修正:

```
下処理 → 加熱調理（揚げ） → 加熱調理（スチコン） → 加熱後
      → 計量・小分け → 真空包装（副菜） → 真空包装（主菜） → 冷蔵で出荷
```

最後の1枚のキャプションが、FB2への直接の回答にあたる:

> **冷蔵で出荷** — この状態で施設へ。届いてから再加熱します。

キャプションは写真を1枚ずつ開いて中身を確認してから記述した。
FB3で指摘された「ピッキングの写真」は `kitchen-weigh.jpg`（計量しながら小分けする作業）で、
「計量・小分け／施設ごとの食数に合わせて計量します」とラベルを付けた。

### 2-2. ギャラリー導入文の変更 — FB1・FB2

**対象**: `index.html`

```diff
- 下処理から加熱、包装まで。セントラルキッチンと施設厨房の日常です。
+ 大分市の自社セントラルキッチンで、下処理から加熱、急速冷却、真空包装まで。
+ パックのまま冷蔵でお届けし、施設の厨房で再加熱・盛り付けをして提供します。
```

「どこの厨房か分からない」と「パックのまま提供されると誤解される」の両方に効かせている。

### 2-3.「届いてからの1日」セクションを新設 — FB6

**対象**: `flow.html`（`id="day"`）

これまで `flow.html` には「相談 → 現地調査 → 見積 → 試食 → 契約」＝**契約までの流れしかなく**、
導入後に現場がどう回るのかを説明したページがサイトに一枚も無かった。そこを埋めた。

| | 見出し |
|---|---|
| 01 | 冷蔵のパックで届く |
| 02 | その日の分だけ再加熱する |
| 03 | 利用者様ごとに盛り付ける |
| 04 | 配膳して提供する |

締めに「朝・昼・夕とも同じ流れです。仕込みと調理はセントラルキッチンで完結しています。」を追加。
`meta description` と `og:description` にもこの流れを追記した。

**現状は文章のみ。写真は入っていない。**
納品・再加熱・盛付の写真が手元に無く、空の枠を本番に置くと壊れて見えるため。
写真が届き次第、写真つきに差し替える。

### 2-4. alt属性の誤りを修正（作業中に発見）

`kitchen-tray.jpg` が「施設厨房で盛り付けるスタッフ」として使われていたが、
実際は**セントラルキッチンで揚げ上がりをバットに並べている写真**だった。
`index.html:258` と `service.html:89` の2か所を修正。

→ 結果として、**「施設で盛り付けている写真」は現在1枚も存在しない**ことが分かった（後述の撮影依頼に含む）。

### 2-5. CSS

`assets/css/style.css` の `.marquee__track` をキャプション対応に変更。

- 固定高さを `li` から `img` に移動（`li` は高さ自動、キャプション分伸びる）
- カット間の余白は `li` の `padding-right` で確保
  → `gap` を使わないのは、ループのため `translateX(-50%)` で半分ずらしており、
    外側に隙間を持つと半コマぶんズレるため
- `figcaption` と工程ラベル `.step`（ブランド赤）を追加
- SP時（`max-width` ブレークポイント）も同様に調整

### 2-6. 配色の調整

`flow.html` に新セクションを挟んだ結果、グレー背景のセクションが2つ連続して境目が消えたため、
FAQセクションを `sec--grey` → `sec` に変更し、白 → グレー → 白の交互配色（サイト共通のリズム）に戻した。

## 3. まだ対応できていない2点

### FB4: 朝・昼・夕の写真

手持ちの `meal-01`〜`meal-12` は**すべて昼夕の定食**で、朝食の写真がゼロ。撮影が必要。

### FB5: コストの例

指摘は正しい。「無料相談できます」だけでは、予算が合うか分からず問い合わせを見送られる。
ただし委託料は食数・食形態・委託範囲で変わるため、単価表は現実的に出せない。
また、こちらで金額を作ることはできない（事実でない数字をサイトに載せることになる）。

**代案は3つ。O.C.K側の判断が要る。**

1. モデルケースの月額を出す（例：50床・朝昼夕150食/日 で月◯◯万円）
2. 金額は出さず、既に載せている「1日18時間 → 10時間」「調理担当1名・8時間分を削減」を
   **人件費換算**で見せる（例：時給◯円 × 8時間 × 30日 ＝ 月◯万円相当）
3. 「料金は食数・食形態・委託範囲で決まります」と**決まり方だけ**を示す

2案が現実的。既存の実績値を使うため新しい数字を作らずに済み、金額表も出さずに済む。
必要なのは換算に使う単価の承認のみ。

## 4. お願いしたい写真（3種）

| # | 何の写真か | なぜ必要か |
|---|---|---|
| A | パックが施設に**届く**ところ（納品・検収） | FB2・FB6の核心。届いてから厨房を通る絵が無いと誤解が消えない |
| B | 施設厨房での**再加熱** / **盛り付け** | 同上。かつ現状「施設で盛り付けている写真」が1枚も無い |

スマホ撮影で十分。厳密なアングルは不要で、工程が分かればよい。

## 5. FBへの返信文（そのまま送れる形）

サイトへのフィードバック、ありがとうございました。
どれも具体的で、実際に直すべき箇所がはっきりしました。6点すべてに方針を決めたので共有します。

**すぐ直した分**

パック詰めの写真の件、ご指摘のとおりでした。あの写真には画面上に説明が一切出ておらず、
無言でパックが3枚流れる作りだったので、「これで提供されるのか」と読まれて当然の状態でした。

写真1枚ずつに工程名を出すようにして、並びも実際の順番（下処理 → 加熱 → 計量・小分け → 真空包装 → 出荷）に直しました。
最後の1枚には「この状態で施設へ。届いてから再加熱します」と入れています。

「何の写真か分かりづらい」というピッキングの写真も同じ対応で、「計量・小分け」と分かるようにしました。
確かに扱いのある方でないと読み取れない写真だったと思います。

**一番効くと感じたご指摘**

「届いてから現場でどう流れるのかを見せる」という最後のご提案が、いただいた中で一番効くと思いました。
確認したところ、サイトには「契約するまでの流れ」しか載っておらず、
**導入した後に現場がどう回るのかを説明したページが一枚もありませんでした。**
検討する施設が一番知りたいところが、まるごと抜けていたことになります。

導入の流れのページに「届いてからの1日」を新しく追加しました。
冷蔵のパックで届く → その日の分だけ再加熱 → 食形態に合わせて盛り付け → 配膳して提供、の4段階です。

ただ、**今は文章だけで写真が入っていません。**
納品の場面と、施設の厨房で再加熱・盛り付けをしている写真が手元に無いためです。
空の枠を置くと壊れて見えるので、写真が届いてから差し替える形にしています。

**お願い（写真3枚）**

もし現場で撮れるようでしたら、以下をお願いできないでしょうか。スマホで十分です。

1. パックが施設に届いたところ
2. 厨房で再加熱している／盛り付けているところ
3. 朝食の提供例

3番は「朝・昼・夕それぞれの提供が分かる写真を」というご指摘に対するものです。
確認したら、今ある食事の写真12枚は全部が昼と夕の定食で、朝食が1枚もありませんでした。

なお作業中に、施設で盛り付けている写真として使っていた1枚が、
実際にはセントラルキッチンで揚げ物をバットに並べている写真だったことが分かり、こちらは修正済みです。
つまり今、施設側の作業風景の写真が実質ゼロという状態です。2番が特に助かります。

**値段の件**

これも仰るとおりだと思います。「無料相談できます」だけでは、
予算に合うかも分からないまま問い合わせることになるので、面倒に感じられて当然です。

ただ委託料は食数・食形態・委託範囲で変わるため、単価表という形では出せません。
代わりに、金額そのものではなく**コスト感が伝わる見せ方**をO.C.K様に提案しているところです。
すでにサイトに載せている「1日18時間の厨房作業が10時間になる」「調理担当1名・8時間分を削減」という数字を
人件費に換算して見せる形であれば、新しい数字を作らずに済み、判断材料にもなります。
これはO.C.K様の承認が要るので、確認待ちです。

**1点だけ、やり方を変えさせてください**

「厨房が広く清潔すぎるので『写真はイメージです』と添えては」という点です。
ご心配の中身はよく分かるのですが、**あの写真はO.C.K様の実際のセントラルキッチンの写真**なので、
「イメージです」と書くと、かえって「これは借り物の写真です」と自分から言っているような形になり、
信用を落としてしまいます。

心配されているのは「イメージかどうか」ではなく「実際より大きい施設に見えないか」だと思いますので、
そちらに効く形で、事実を書き足す方向にしました。
ギャラリーの冒頭を「大分市の自社セントラルキッチンで、下処理から加熱、急速冷却、真空包装まで。
パックのまま冷蔵でお届けし、施設の厨房で再加熱・盛り付けをして提供します」に変更しています。
どこの厨房なのかが先に分かるので、"どこかの大きな工場" という印象は薄れるはずです。

受託施設数や1日の食数を出せれば規模はさらに正確に伝わるので、こちらもO.C.K様に確認中です。

引き続き、気づいた点があれば遠慮なく教えてください。
